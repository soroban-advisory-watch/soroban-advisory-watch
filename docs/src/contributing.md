# Contributing

The full guide is [CONTRIBUTING.md](https://github.com/soroban-advisory-watch/soroban-advisory-watch/blob/main/CONTRIBUTING.md) in the repository. In short:

1. This project takes part in the Drips Stellar Wave Program. Find an issue, apply through Drips, and wait to be assigned before you start.
2. One issue per pull request. Keep the change to what the issue asks.
3. Run `cargo fmt`, `cargo clippy` and `cargo test` before pushing.
4. Do not change files in `advisories/osv/` by hand. They are upstream data.
5. Report security problems privately. See [SECURITY.md](https://github.com/soroban-advisory-watch/soroban-advisory-watch/blob/main/SECURITY.md).
