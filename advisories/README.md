# Advisory data

- `osv/`: OSV records copied unchanged from the [GitHub Advisory Database](https://github.com/github/advisory-database) (`advisories/github-reviewed/<year>/<month>/<id>/<id>.json`). Licensed [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/) by GitHub.
- `annotations.toml`: this project's notes on each advisory (conditions and signal ids).

Do not edit files in `osv/` by hand. To refresh a record, copy the newer file from upstream. See the [Advisory data](https://soroban-advisory-watch.github.io/soroban-advisory-watch/reference/advisories.html) page for how to add one.
